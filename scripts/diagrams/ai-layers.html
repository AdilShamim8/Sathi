The AI Layer Split — who computes what
Four strictly separated layers. Money math is deterministic and auditable; ML adds calibrated probabilities with baselines always reported; the LLM only chooses words for numbers it is given; RAG grounds conversation in a curated corpus. Any answer that breaks the contract is discarded — fail-closed.
LAYER 1 · DETERMINISTIC
Rule Engines
single source of truth for every ৳ figure
Safe-to-spend — liquid − commitments − buffer − prorated goals (safeToSpend.ts)
Recurring detection — MAD regularity + monthly anchors, from history only
Categorizer — rule chain, reason trace per txn (bn/en)
Fee & cash-out math — bps half-up rounding, agent audit
EXACT — auditablesame inputs ⇒ same taka, every time · 40 ported engine tests
LAYER 2 · MACHINE LEARNING
Forecast & Risk
calibrated probability, never raw point guesses
LightGBM quantile ensemble — 9 quantiles, direct 1–35-day horizon (lightgbm.ts)
P(shortfall) — Platt-calibrated, split-conformal widening
Liquidity paths — block-correlated simulation, zero-floor wallet
30 leakage-safe features — scale-free, no persona/id/ground-truth inputs
VALIDATED — vs baselinesBrier · pinball · coverage · PR-AUC, on frozen held-out users
LAYER 3 · LLM
Language Only
words for numbers it is handed — nothing else
Intent routing — 10 copilot intents, deterministic dispatch
Phrasing — Bangla / English explanation drafts
Template rendering — 13 templates × 2 locales, always available
Forbidden — arithmetic, new numbers, advice not backed by evidence
GROUNDED — or discardednumeric parity check on every draft · audit-logged
LAYER 4 · RAG
Knowledge
curated corpus, retrieved — never invented
BM25-lite retrieval — 10 financial-knowledge docs (knowledge.ts)
Chunk citations — source id + title shown with every use
Scope — product & financial-literacy Q&A only
Separation — retrieval feeds context; it cannot touch money math
CITED — or omittedno retrieval hit ⇒ the assistant says what it doesn't know
OUTPUTSExact ৳ amounts, category labels, reason traces, fee totals
OUTPUTSp10 / p50 / p90 daily paths, P(shortfall) 7-day, trough date
OUTPUTSbn/en sentences — numbers unchanged from Layers 1–2
OUTPUTSRanked doc chunks with citations for the answer
Fail-closed conversation pipeline every Copilot / v1 chat message walks this path — a draft that fails any gate is replaced, never shown
